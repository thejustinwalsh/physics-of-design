# Approved content and product facts

Brand: Design Theory
Optional descriptor: The physics of better interfaces.
Suggested hero: Make every choice work together.
Hero explanation: A local-first toolkit that helps coding agents explore typography, color, layout and motion as one connected design. Give it a direction. Compare possibilities. Measure what lands.
Primary CTA: Explore the tools (local features anchor)
Secondary CTA: View on GitHub (repository URL in BRIEF.md)

Feature meanings to convey (wording and presentation can vary):
- Typography that holds together: font metrics, variable axes, tracking, leading, measure and line breaks are related choices. Verify actual browser or native output.
- Color with a purpose: explore perceptual OKLCH palettes, assign roles and check scoped text contrast. Palette harmony is a choice; legibility is checked.
- Layout that responds: reason about hierarchy, grouping, whitespace and responsive relationships. Adapt to content and available space rather than freezing one screenshot.
- Motion with intention: express tension, timing, continuity and release through editable motion relationships. Respect reduced motion and real platform behavior.
- Materials and light: explore texture, roughness and light response. DOM finishes are visual approximations; dedicated graphics can use PBR. Verify readability on the actual composite.
- Decisions you can revisit: tools retain alternatives and provenance. A small optional local selector chooses among viable options; saved paths can be replayed without another model call when inputs still match.

Workflow in plain language:
1. Set a direction — record the audience, content and visual intent in DESIGN.md.
2. Explore the relationships — compare coupled alternatives instead of guessing one number at a time.
3. Measure the result — use real font shaping and browser/native geometry; catch wrapping, clipping and constraint failures.
4. Keep the good path — save decisions, revisit values and revalidate when the content or context changes.

Tooling facts:
- Unix-composable TypeScript CLI with JSON output and thin MCP wrappers.
- Optional interactive specimens and component inspection resources.
- React + StyleX and React Native mappings; platform-specific verification remains necessary.
- Local-first operation after provisioning. The optional selector is not an aesthetic judge or factual verifier.
- MIT-licensed source, with a pay-it-forward invitation to contribute fixes.
- Authoring tools can guide ordinary application code. Shipping the optional evaluator is a separate choice, not a required service.
