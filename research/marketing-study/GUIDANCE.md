# Design guidance — frozen practitioner principles

Start from audience, real content, visual intention and the task. Build a coherent narrative and distinguish primary, secondary and supporting information. Prefer specific prose to broad claims. Preserve the direction while testing alternatives.

Compose relationships: title/prose hierarchy, line length, leading, tracking, semantic grouping and adjacent whitespace should respond together. Use font metrics and actual rendering when judging fit. Avoid arbitrary font prohibitions or universal ratio claims. Similar purpose can establish a rhythm; a deliberate exception can create emphasis.

Choose color by semantic role and perceptual lightness/chroma, then verify actual text/background contrast. Use accent sparingly enough that emphasis means something. Textured and translucent backgrounds need composited readability checks. A palette alone is not a visual identity.

Let composition create visual interest: contrast scale, shape, density, finish and negative space while preserving reading order and access to actions. An asymmetric layout can be balanced without matching every rectangle. Use imagery with intentional focal crops; align peers and edges when their semantic relationship calls for it. Avoid identical card treatments for unrelated ideas.

Responsive design changes relationships and topology, not merely all sizes by one multiplier. Respect content height, minimum useful text measure and controls. Treat phone, tablet and desktop as distinct scenarios. Keep natural scrolling and readable content at other widths/heights. Text enlargement and changed content are normal inputs.

Motion should reveal structure, connect states and create intentional tension/release. Establish a hierarchy of pace and movement. Parallax needs enough relative movement to be visible, while text and controls stay readable and operable. Avoid animating every element identically. Use transforms/opacity carefully; pause hidden work, clean up clocks/listeners and respect reduced motion. Actual intermediate frames and interruption tests are stronger evidence than parameter values.

Materials need coherent lighting, diffuse body, texture scale and restrained specular contrast. DOM material layers are approximations. Compare actual surfaces under the same light and check text through light poses; don't assume a nominal swatch verifies the final composite.

Measure first-delivery output in real browsers. Test continuous pointer and keyboard interaction, current geometry, resizing, changed text, enlargement, reduced motion and cleanup. Keep alternatives and editable choices. A numerical compatibility value, confidence readout or synthetic critique does not establish beauty. Record failures honestly.
