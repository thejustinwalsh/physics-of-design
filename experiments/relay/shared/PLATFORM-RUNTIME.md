# Shared native runtime access

Read `BUILDER.json` → `runtime.devices.tools` for the actual host-provisioned Android `adb`, iOS input-runtime directory and custom Simulator set. These paths are supplied equally to every builder at preparation. `runtime.devices.ios` and `.android` identify the already provisioned Simulator/emulator; the devices are shared sequentially. Do not create a default Simulator set or modify host directories. Use the assigned Metro/proxy/observer ports. Expo Go is already installed (`host.exp.Exponent` on iOS, `host.exp.exponent` on Android).

Use the supplied `toolkit/scripts/ios-input-driver.mjs` with `DESIGN_IDB_RUNTIME_DIRECTORY` set to the descriptor's `iosInputRuntime`, `DESIGN_IDB_STATE_DIRECTORY` inside `app/evidence/ios-input`, and `DESIGN_IOS_DEVICE_SET` set to its `simulatorSet`. `start UUID` runs a foreground companion; retain its process handle, record it, and stop it after validation. `ax`, `tap-id`, `swipe`, `text`, `key`, and `screenshot` operate on actual native controls. Query fresh accessibility geometry before tapping and verify the resulting app state. A dispatch receipt alone is not a successful task. Keyboard text input remains unverified by the spike and needs your actual field test.

Android uses the descriptor's `androidAdb` executable and explicit serial, UIAutomator accessibility bounds, real `input` operations, and saved screenshots. Reverse both Metro ports and your observer port as required by the emitted manifest. Native measurement must come from the app's actual Text/host-node geometry; browser values cannot be relabeled native.

The blank shell's `useObservations` adapter exposes current host-node boxes through refs and optional local observer delivery. Keep new observation data separate from declared styles. The compiled browser assets are useful for web tuning, but do not replace the actual native flows. Record every runtime child in `app/evidence/runtime-processes.json`, stop it, and preserve current receipts. Use the common brief/report contract to decide completion.
