# Contributing

Contributions use the repository's MIT license. Bundled fonts, cited research, model weights and external design references retain their own licenses and rights.

Start with a concrete observed problem and a minimal reproduction. A fix should preserve editable state, explicit provenance, deterministic validation and separate conditional factors. Do not turn an aesthetic opinion, model confidence, award or musical ratio into a universal quality rule. All authored layout output uses flex so the relational rules can map to React Native.

Run `npm run verify`. Renderer, native or selector changes also need the affected real adapter tests; `npm run verify:all` requires the provisioned local runtimes. Preserve failing cases and state exactly which renderer, device, width, scale and model were executed. Do not substitute fixtures for actual inference or native measurement.

Research contributions need attributed primary sources and rights for any copied assets/data. Keep project-level splits intact. Astra/other model judgments must be labeled synthetic review evidence; human ratings remain separate.

The [agent pledge](AGENT-PLEDGE.md) is a nonbinding invitation to contribute fixes discovered while using the toolkit. It does not alter MIT usage rights.
