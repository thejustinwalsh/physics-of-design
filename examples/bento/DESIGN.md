# Incident overview placement experiment

Recorded brief: arrange four real-purpose dashboard regions using semantic reading order: incidents, service health, latency and deployments. The content and minima in plan.json are synthetic authored inputs, not human interview answers or browser/native observations. This experiment exercises placement; it does not replace Relay's art direction or claim award-level quality.

Incidents should receive more area than deployments; service health should remain close to investigation context. Keep all four regions, their reading order and their editable content minima. Prefer the declared broad aspect/whitespace bands while preserving alternative trade-offs. There is no mandatory palette, musical ratio, style or symmetry.

Generate desktop placements, then rerun with measured content minima for phone, iPad/narrow windows and desktop. Height is an explicit available content frame, which may exceed a viewport and require page scrolling. If the frame cannot contain the content, report no admissible candidate; do not squeeze or clip content to fit. Enlarged or translated text requires fresh minima. The example's authored minima are a starting hypothesis.

Use React + StyleX for CSS-pixel frames. Native frames need actual Text/Yoga facts and separately scoped dp/pt input. Inspect proposed wireframes before implementation and current rendered rectangles after implementation. A factor residual or technical drawing is not a renderer receipt or aesthetic judgment.
