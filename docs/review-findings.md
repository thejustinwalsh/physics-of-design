Findings are accepted only when they have an observable failure and a distinguishing check. Review covers authored source, emitted contracts, subprocess boundaries, browser/native lifecycle, corpus and evaluation; generated/vendor code is reviewed through its contract.

Further responsive review found and fixed two concrete regressions. A wrapping flex column let Yoga place supporting text in a second column; reading stacks now explicitly use nowrap, row patterns retain wrapping, and native viewport containment is a hard check. The interactive proof also retained manually written inline font sizes after React updates, blocking later responsive resizing; edits now update the shared React state and clear those stale overrides, with a resize-after-edit regression test.

The complete initial Android matrix exposed hanging-space widths and overfull default paragraph breaks; these led to native trimmed-line probes and explicit simple breaking. Lines without trailing spaces keep their native context-shaped width. The final matrices, rather than a relaxed tolerance, determine acceptance.

The color review corrected achromatic hue handling and union-area geometry at tiny viewport scales, and tested exact contrast thresholds, gamut-mapped candidate checks, locks, duplicate rectangles and affine invariance. Contrast applicability now uses authored web size before user enlargement and a conservative native text threshold. Actual browser and native palette output is verified separately from the pure color equations.

The tiny selector probe exposed answer-order instability. Balanced readout canonicalizes prompt-bearing candidate sequences, validates every row, preserves candidate-to-option identity and aggregates finite logits (or strictly positive log probabilities). Partial batches and zero probabilities without logits fail closed. Synthetic protocol tests are distinct from actual model inference. Final code review and measured follow-up are recorded in [selector-and-training.md](selector-and-training.md).
