## Reproduced failures and shared corrections

The original continuous-pointer capture is retained at `artifacts/design-theory/interactions-before/`. At a 390px viewport the gutter rail moved 208.25px and the page scrolled 187px during one drag. The content-gap rail also moved 9px. The trace and midpoint screenshot show the control below a changing preview. At 834px the first gutter interaction moved the rail 17.62px. The motion/material controls had stable geometry but some phone material runs included long tasks. These are local observations with capture overhead, not controlled hardware benchmarks.

The corrections address reusable causes:

- Native range thumbs track input immediately; latest values publish once per animation frame and the final value flushes on pointer release, keyboard release or blur. Saved/replayed external values still update the native control.
- Interactive sections no longer animate their entire control coordinate space into view. The decorative registration strip alone follows bounded scroll progress, with a static reduced-motion state.
- Phone layout controls precede the changing preview, and desktop controls align at the top. Natural text measurement runs before paint, retains the prior measured height during a change, and never publishes a temporary zero measurement.
- Memoized section boundaries keep unrelated layout/crop/material studies out of App-level motion updates.
- Surface configuration is diffed and coalesced on the existing clock. A normal-scale/relief-only edit no longer resends both surfaces and regenerates both roughness maps. Main-thread updates no longer render synchronously in every React input effect; visible surface draws retain the 30fps cap and one worker frame in flight.
- Button release restores the pressed button even when the pointer ends elsewhere. Clipboard denial now has an explicit fallback message and selectable command.

The interim 390px retest had zero rail and scroll movement across all eight original sliders and no observed long tasks during those drags. A remaining tablet/desktop entrance-transform drift was then removed. Final current-source results are recorded separately below when the full suite completes; the interim run is not substituted for final evidence.
