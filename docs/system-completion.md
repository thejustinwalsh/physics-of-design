# System acceptance ledger

This ledger separates implemented engineering, executed evidence and claims that remain unknown or failed. The [whole-system report](system-report.md) gives measurements and limitations. The expanded Fieldwork composition proof is part of acceptance, not a replacement for the renderer/tool tests.

| Requirement                          | Outcome and evidence                                                                                                                                                                                                                                                                            |
| ------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Registry, evidence classes, licenses | Implemented source-attributed empirical/standard/heuristic/hypothesis registry, OFL font manifests, MIT code and voluntary agent pledge. [Research ledger](research-ledger.md).                                                                                                                 |
| Typed variables and coupling         | Editable typography/color/responsive state, safe perturbation, locks, invalidation, bounded multi-candidate refinement and separate Pareto factors. Regression/property tests cover negative boundaries.                                                                                        |
| Unix CLI / MCP                       | 24 shared validated commands, JSON streams, stderr errors; compact discovery and exact session references; opt-in full wrappers. Command conformance and actual App SDK bridge are executed.                                                                                                    |
| Shaping / web                        | Actual Fontkit, compiled React + StyleX and Chromium lines/geometry; Arabic/axes, wrap thresholds and scoped text-spacing checks. No final glyph-ink or fallback-chain parity claim.                                                                                                            |
| Native measurement                   | Actual RN Text/Yoga on iOS phone, iPad and Android emulator; bridge leases/font identity/content checks, system scaling and native failure/recovery. [Runtime coverage](system-report.md#actual-runtime-coverage).                                                                              |
| Intervals / rhythm                   | Log ratios, configurable multi-peak curves, off-scale alternatives, ordered motifs and local entropy. Numeric aesthetic coefficients remain uncalibrated.                                                                                                                                       |
| Responsive patterns                  | Shared flex-only resolution, minimum-measure fallback, bounded reading caps, actual container resizing and native platform tests. Actual window versus virtual artboard evidence stays distinct.                                                                                                |

The intended 20% efficiency reduction was not demonstrated.                                                                                                                         |

No synthetic score substitutes for human evidence.                                                                                                              |

No training performed; data too small for taste calibration.                                                                                                       |
| Full design bar                      | Fieldwork web cover/issue/story plus genuine RN journal/search, saved and reader views. Actual screenshots, HIG frame records, alignment checks and task-flow verification; [review and closure](fieldwork-design-followup.md) records initial findings and subsequent dispositions separately. |
| Review / reproducibility             | Independent Astra code/design reviews, distinguishing regressions, complete 15-stage lane, additional current-source checks, portable evidence export and CI. Historical interrupted/failed runs retained with scope.                                                                           |

The scientific conclusion is scoped: the infrastructure is useful for making relationships measurable and revisable; preference superiority and efficiency improvement are not established. The tiny selector fits, but its design judgment is not ready to be trusted. Engineering acceptance does not transform those negative/unknown results into validation.

The whole-app examples were implemented with substantial human direction and explicit Astra review prompts. The unsteered complete-product/tool-discovery experiment has not run. The central search state still focuses on two text archetypes; the composition planner and geometry audit are separate tools. No general component catalog, Figma/DTCG import/export or whole-app component compiler is claimed. See [the complete landscape](landscape.md).
