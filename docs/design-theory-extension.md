Project MIT terms do not replace third-party licenses; GSAP retains its own standard license.

`validation plan` and `validation check` add a separate XState gate for authored phases and responsive/tool obligations. Current design/plan/input identities and matching evidence kinds bind receipt declarations. Missing, stale, failed and unknown checks block advancement. A live receipt update restarts earlier guards. The gate does not execute or authenticate validators; the example feeds it six actual geometry/palette results and deliberately withholds an iPad result to prove blocking. ## Typography precision

The new inspector separates actual vector outlines and positioned glyphs from base global metrics, DOM selection fragments, geometry-preserving baseline probes and Canvas drawing-state metrics. The CLI applies responsive resolution and user enlargement before measurement. A bounded axis wizard samples all 13 Roboto Flex axes at minimum/default/maximum plus the requested state: 40 candidates per engine. Each engine observed 11 geometry-changing candidates and eight wrap-changing candidates in the fixture. Two engines passed 26 proof checks; this is endpoint coverage, not every axis combination.

The audit found real faults. Spaces previously emitted infinite per-glyph rectangles, which JSON silently turned into null fields; empty outlines now return null while preserving advances, with a semantic migration. Legacy editor probes could change Arabic shaping and then draw the wrong baseline; the editor now uses the same guarded collector and omits unavailable guides. WebKit's explicit-opsz/auto-sizing geometry differs from Chromium in the recorded case. Resolved browser axis coordinates remain unknown, fontkit global metrics are labeled MVAR-unresolved, and Canvas parity is not asserted. Native baseline/axis extraction and raster paint bounds remain unsupported. See [measurement details](typography-measurement.md) and [independent review](typography-review.md).

## Material principles

`surface probe` exposes a named, linear-RGB Lambert/GGX/Schlick/Smith model. Roughness is mapped to microfacet alpha; the probe declares its single-scattering/lighting omissions and does not claim exact energy conservation or Three pixel parity. Data textures retain channel, UV and color-space semantics. A photograph with baked illumination is not calibrated albedo.

`material pair` calculates separate parameter relationships. OKLab distance describes base-color swatches; roughness/alpha/metalness differences describe the chosen model; texture frequency includes physical scale only when supplied. Shared lighting IDs are declarations, not measured equivalence. Text overlay legibility remains unknown until the actual composite is measured.

The Disney and Filament work supports principled material controls. Material-perception experiments support dependence on illumination and geometry. They do not validate a universal pleasing-pair equation. Authored pairing bands are therefore explicit art direction, suitable for comparison and later calibration. See [material research](material-pairings.md) and [image/texture rules](material-image-rules.md).

## Proof surfaces and research limits

Vela gains visible descendant entrances, spring press response and completion movement from reusable motion functions, with reduced-motion cleanup. The developer gallery demonstrates different editable directions, motion, materials, imagery, decision paths and technical drawings in React + StyleX flex layouts. Its source and runtime receipts accompany the extension evidence.

Playwright Chromium and WebKit both created worker WebGL2 contexts on this Mac. A pure-math microbenchmark excludes rendering, layout and IPC, so it does not establish complete-app performance. Physical Safari, sensor permission/hardware behavior and native tilt integration are not certified by those tests. The previously verified native app source remains a separate proof; browser material/scroll adapters do not imply native rendering parity.

The wireframe App host has real bridge coverage for variable edits, dependent redraws and human node selection. Independent review identified stale asynchronous response races, invalidated redraws and mutable receipt definitions; fixes and delayed-response regressions are recorded in [the integration review](extension-integration-review.md).

The prose example preserves identical copy while changing navigation. ## Verification and publication scope

The final local verification lane passed all 19 ordered stages in 181.205 seconds: 269 unit tests, seven browser integration tests, 18 command/App/policy tests covering all 55 commands through CLI and MCP, and the remaining responsive/product proofs. It includes the complete unit/command/MCP/App contracts, existing responsive app proofs, current gallery/motion, validation guards, both-engine typography and the semantic migration fixture. The first expanded run preserved one configuration failure: the gallery runner could not find WebKit in Playwright’s default cache. The complete lane was rerun with the provisioned WebKit path explicitly supplied; no checks were weakened. The full native/hardware lane is separate. [Curated receipts](../evidence/design-theory-2026-10-25/README.md) bind published artifacts by SHA-256; runtime bundles, model weights and caches are excluded. Compact MCP discovery remains three tools and 1,799 wire bytes; the optional full profile exposes 58 tools and 205,632 wire bytes. The coverage-summary regression shrank a 4,096-character missing-font case from 197,357 to 5,681 bytes while retaining exact data behind the result reference. These are bytes, not token-savings evidence. The prior native app implementation identity is checked before reusing its historical evidence.

The [independent gallery review](gallery-astra-review.md) closes state export/replay, narrow-screen content containment, technical-drawing equivalence and initial-frame findings. Synthetic critique is not human preference. PBR initialization is visibly asynchronous and retains a static fallback until a matching current-size frame is acknowledged. Browser WebKit evidence is not a physical Safari performance certificate.

## Conclusion

The extension provides reusable relationships and executable choices across more design dimensions, with demonstrable local choice reuse and inspectable human edits. No human preference, award quality, universal material harmony or lower token cost has been established. Musical priors remain optional and unvalidated; the factor engine does not depend on them succeeding.
