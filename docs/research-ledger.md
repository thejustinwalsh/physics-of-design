## Implementation evidence categories

- **Measurement:** actual font metadata, glyph positions, primary glyph coverage, renderer lines/rectangles, wrap brackets, native events and runtime identity.
- **Standard:** scoped text-spacing override tolerance in applicable web specimens.
- **Empirical:** published studies/reviews, with their populations and domains retained in the registry.
- **Heuristic:** smooth targets, density neighborhoods, tracking interpolation, leading/measure/gap suggestions and bounded-search budgets. Their numbers were chosen for this spike and have no fitted confidence interval.
- **Hypothesis:** musical hierarchy landmarks, visual interval expectations and any claimed preference advantage. Disabled by default.

No licensed award corpus has been assembled and no aesthetic compatibility curve is calibrated. A six-record original CC0 pilot and six-pair synthetic Astra batch exercise corpus/export mechanics. `research/corpus-record.schema.json` requires attribution, permissions, font licenses, genre/audience/year/platform strata, matched production controls and project-level split identity. Keep all perturbations/viewports of a source project in one split. Screenshot-only inference cannot supply font metrics or responsive rules.

## Prospective falsification

[The frozen screening plan](../research/evaluation-plan.json) uses one agent and one provisional selector with three conditions: guidance only, tools with smooth priors, and tools with musical priors. Two archetypes only. Musical versus smooth isolates the ratio hypothesis; guidance versus tools tests the system's practical usefulness. Record ties, first-pass preference, tokens, latency, attempts, hard failures and unseen-content/width stress. Cluster by project. Inadequate observations remain undetermined; adequate evidence of no practical advantage discards musical priors without discarding the factor engine.

The evaluation CLI consumes observations; it does not invent rater judgments or agent token counts. Protocol fixtures and renderer smoke tests are not evidence of human preference, lower token usage, fewer attempts or quantized-selector quality.

## Execution update

The registered protocol remains prospective for human preference and practical acceptance. Twelve same-agent state-decision trials were executed on four projects: tools increased tokens/latency, attempts stayed at one, and all recorded renderer checks passed. No human preferences exist. [Whole-system report](system-report.md) gives exact outcomes and limits. Thresholds were not changed after observing this result.

Two isolated Astra raters inspected 36 original specimen images across phone/tablet/desktop. Their six project-level choices retain synthetic provenance, ties, an exposed-configuration abstention and a preassigned project split. No numerical aesthetic equation was fitted from this small confounded batch. The tiny selector's original probe failed order stability; the balanced follow-up addresses the protocol, not aesthetic validation.
