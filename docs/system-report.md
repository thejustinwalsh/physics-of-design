## What is reusable

[The factor-engine explanation](factor-engine.md) describes the implemented equations and their evidence boundaries. Logarithmic intervals, configurable multi-peak curves, ordered spacing motifs and local entropy are mathematical descriptors. Separate relationship factors retain provenance and uncertainty. No universal beauty score exists. The numerical typography proposals and responsive anchors are editable heuristics, rather than empirical musical laws.

A perturbation returns a new state and transitive invalidation. Search changes neighboring tracking, leading, measure, hierarchy and gaps, observes actual discontinuous line breaks, refines locally, and verifies base plus responsive scenarios. It preserves multiple viable alternatives and a Pareto frontier. Invalid numerical proposals are reported before rendering. Stale state/font receipts are rejected. SemIf receives only freshly verified choices and returns no validity or aesthetic confidence.

The shared responsive resolver interpolates bounded, source-attributed anchors for type, spacing and measure. Both outputs use explicit flex direction, wrapping, grow, shrink and basis. Reading stacks use nowrap. Optional two-block rows require both minimum text measures to fit at effective text scale; otherwise they stack. Web observes container width. Native hosts supply measured window/container context, and system text enlargement stays additional. These rules generalize across input content; no fixed title breaks or content-specific overflow exceptions were introduced.

## Corpus, licensing and remaining capability limits

The attributed registry separates empirical sources, standards, measurements, heuristics and hypotheses; [the research ledger](research-ledger.md) records corrected bibliography and scope. Font files have pinned source revisions, byte checksums and bundled OFL notices. Corpus commands validate rights, attribution, strata, award claims, matched controls, perturbation ancestry and project-level holdout. A CC0 original arrangement/text pilot has six records and 36 rendered observations. Fonts retain their own licenses. This establishes corpus tooling, **not an assembled licensed award-winning dataset or calibrated preference model**.

The native adapter explicitly rejects custom axes/automatic optical sizing, disabled kerning and arbitrary feature toggles. RN0.88 exposes a variation-settings API; that path is not validated by this adapter, so unsupported does not mean the platform can never support it. Web variable axes and Arabic shaping are exercised; native static licensed faces are exercised. Primary-font missing glyphs fail until a verified fallback-chain adapter exists. Language-specific reading quality, final renderer glyph ink, full WCAG conformance, physical devices, other browser engines and React Strict DOM parity remain outside the verified capability contract.

The root dependency audit reports zero known vulnerabilities. The optional pinned Expo development toolchain reports five high-severity transitive entries involving node-forge/Zod; no compatible upstream repair was available in the tested SDK. The audit JSON is retained under [artifacts/review](../evidence/review). No forced incompatible SDK downgrade was applied.

The engineering conclusion is to keep the measurement/factor/search stack and responsive rules as executable, revisable infrastructure. The efficiency goal failed this limited pilot; musical preference is unestablished. The implementation now makes both claims testable without baking either into a score or a fixed demo design.
