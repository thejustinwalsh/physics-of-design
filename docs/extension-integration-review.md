# Extension integration review

Independent review of the new wireframe, MCP App, and command integration on 2026-10-25. The review used real MCP calls and the real AppBridge/Chromium host with deliberately held responses. It did not infer correctness from the original passing tests.

The pre-fix observations remain in [`artifacts/review/extension-integration-probes.json`](../evidence/design-theory-2026-10-25/review/extension-integration-probes.json). Source was reviewed while the integrating agent was also adding compact summaries; those summary fixes were independently verified by subsequent real calls.

The corrected App uses explicit empty/inspection/specimen/wireframe modes. Host results start a fresh epoch and clear incompatible controls. Async sharing acknowledgments also check view, geometry, and selection identity. Proposed geometry remains distinct from supplied renderer observations: the initial receipts are caller-supplied and are not authenticated by this tool.

The direct mathematical boundary checks rejected undeclared prototype references, invalid arity, unknown/cyclic dependencies, and excessive expression depth in the exercised cases. Labels and embedded JSON remained escaped. No claim is made that every malformed input, transport failure, or browser has been exhausted.

The metadata observation is closed: source inspection confirms full-profile `decision run` and `composition solve` now declare `readOnlyHint: false`, accounting for possible selector audit writes. The integrating agent made this correction.

Verification commands for the correction are `npm run build`, `npx tsx --test test/wireframe.test.ts`, and `npx tsx --test test/app.integration.ts`. The App regression uses controlled response release order, validates final rendered geometry, and exercises real server error results. Build passed. All four real-host integration tests passed, including cross-mode replacement and stale specimen sessions; all eight direct wireframe tests passed. The monotonic frame session is stale-message isolation, not a security credential. Same-origin embedded content is still within the trusted preview surface.

The validation-machine recoverability finding is closed. The original unknown-requirement `RECEIPTS` event stopped the actor permanently. An independent probe against the corrected source now leaves the actor active in `phase0`, clears prior receipts, records `receiptError`, and blocks `ADVANCE`; a subsequent valid matching receipt clears the error and permits completion. The probe used explicitly synthetic fixture receipts, not renderer evidence. Source review also confirms copied and frozen receipt records/context, isolated plan snapshots, and prior-phase revalidation on advance. These are coordination guarantees around caller-supplied declarations, not authentication of their contents.
