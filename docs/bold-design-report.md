It does not claim PBR transport, physical refraction or energy conservation. ## Failures found and corrected

Continuous phone drags previously moved a slider rail by 208px and scrolled the document by 187px. Natural-height resets, controls positioned after growing content, broad React updates and section reveal transforms contributed. Controls now precede growing content on phones, retain measurements and coalesce input; unrelated sections are memoized. Texture changes are diffed instead of rebuilding maps for unrelated scalars.

Eager 3D initialization could block interaction. The default hero now uses live DOM lighting; 3D requires explicit activation, with worker-first rendering and an explicit main-thread fallback. Static original artwork remains visible while unavailable. A captured 3.46-second gap was confounded by video/trace/screenshots; it is preserved without attributing the cause to GPU compilation. Clean trajectories exclude those probes. Local timing does not establish physical-device or general Safari performance.

Independent review also reproduced a slow-response auto-clock stopping before its target and a finalist receipt identity collision after changed leading. Both were corrected with regression evidence. Arbitrary caller recipe notes could expand a compact field summary above 500 KiB; a bounded selection whitelist keeps that metadata behind the exact result reference.
