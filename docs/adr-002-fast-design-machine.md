# ADR 002: fast mathematical exploration and resolved design machines

Status: implemented, with measured limitations. October 2026.

The brief supplies purpose, authored content, visual direction and priorities. A finite mathematical program describes editable variables, derived relationships, responsive scenarios, hard constraints and weighted preference fields. The expensive build agent receives a resolved design machine instead of re-deriving every size, gap and spring in conversation.

For scenario s and factor j, the search energy is

`E(x | brief) = sum_s sum_j weight_j * min_k(distance(f_j(x,s), [low_jk, high_jk]) / scale_j)^2`.

Weights, target bands and scales belong to this brief and retain provenance. Multiple bands form multiple wells. A desirable tension can have a nonzero target; zero tension is not a default optimum. A zero-weight preference is absent. Hard constraints are filtered separately and cannot be bought off by a low energy. The engine also retains individual factors and Pareto information. This is a scoped search objective, not a universal beauty score or a measurement of physical energy.

Expressions use a bounded typed JSON AST, without eval or arbitrary tool execution. Logarithmic ratios, products, thresholds and conditional topology share the same dependency model. Real font advances can provide calibrated inputs. Predicted line footprints remain predictions. Final browser/native shaping, content preservation and accessibility checks remain necessary.

Search enumerates small domains exactly or explores deterministic beam neighborhoods. Every evaluated local mutation is recorded in a choice graph. Finite differences expose per-variable energy pressures and dependent derived changes. Unique-state, expression-work and retained-observation budgets bound the run; an incomplete beam run never claims a global optimum. Invalid numerical domains and invalid machine bindings are rejected without hiding valid alternatives.

System 1 has two distinct execution costs. The measured Vela mathematical lane explored 1,795 coupled configurations in about 1.69 seconds. The optional local SemIf/Qwen readout chooses a small admissible frontier and remains outside that hot loop. The actual CPU readout is substantially slower than the mathematical kernel. A successful search produces a solver recipe and a resolved design machine; an unchanged recipe makes zero neural calls. A build agent can replay the design machine without a model installation.

The resolved machine includes chosen values, editable alternatives, authored default/compact copy, screen purposes, numeric region bindings, guarded transitions, spring plans, build constraints and explicit pending verification. The portable evaluator is shared by Node, browser and React Native. XState v5 executes navigation and guard/reflow behavior. This borrows the bounded state/observation/action approach of [Stately Agent](https://github.com/statelyai/agent); the package uses pinned XState directly, without adding another model SDK or planner.

A cached solver recipe binds the normalized search options, selector profile/readout/token budget and actual checkpoint bytes. The design-machine identity binds the full program, brief, domains, scenario envelope, tool/runtime identities supplied by the caller, content and transition graph. Replay recomputes expressions and guards. Changed policy invalidates reuse. Invalid reflow preserves the last valid live state and reports a need for new search. No cached feasible flag or model confidence establishes correctness.

Vela is the complete product proof. Its generated contract controls hierarchy, leading, tracking, gutters, grouping, radius, rail/pane geometry, navigation fit, semantic compact roles, numeral layout and springs. Independent critique exposed a task-priority failure at large text, despite geometric containment. The resulting rule is footprint-driven compact hierarchy and action-first order, plus authored short-word alternatives and a full-label menu when tabs no longer fit. Full font scaling remains enabled. Real activity takes priority over sample history; an empty timer does not earn a completion.

Remaining limits are explicit: the policy and topology are authored, the local selector has not established superior taste or token savings, source-identity labels must be maintained when external tool implementations change, and no award-level quality or human preference result is inferred from mathematical energy or synthetic critique. Musical priors remain optional hypotheses; the earlier flat-search benchmark remains historical evidence rather than an evaluation of this new loop.
