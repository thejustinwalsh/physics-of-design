# ADR003 — Design Theory: decision paths, motion, materials and reader journeys

Accepted 2026-10-25. Extends the conditional factor engine; preserves the original white paper and previous proof identities.

## Decision

Name the product **Design Theory**. Treat physics, energy, tension, entropy and musical intervals as useful optional languages. Neither a name nor a mathematical descriptor prescribes the resulting style.

Keep deterministic calculations as independently executable JSON CLI commands, with thin MCP dispatch and optional inspection resources. Three default MCP tool descriptions expose discovery, execution and specimens; the command catalog grows without advertising every schema in every prompt. Full payloads remain by exact bounded session reference. Retain the old specimen resource URI as a compatibility alias.

Separate four layers:

1. **Facts and constraints:** actual shaping/renderer receipts, scoped contrast, finite geometry, content preservation and platform support.
2. **Physical and perceptual descriptors:** logarithmic ratios, spring response/work/dissipation, reflectance parameters, color distances, texture frequencies and geometric relationships.
3. **Art direction:** source-attributed, editable conditional bands, role relationships and candidate alternatives. A brief may deliberately prefer overshoot, dense texture or material contrast.
4. **Choice and implementation:** bounded numeric exploration, optional narrow local readouts, saved conditional decisions and platform adapters. Neither selectors nor preference bands verify the facts.

## Conditional paths

`decision run` executes dependency-ordered design stages. Chosen predecessor values condition later programs. Cache identity binds context, programs, search policy, dependency choices and checkpoint bytes. Replay revalidates assignments deterministically and invalidates changed stages. The prepared local session hashes its checkpoint once per run. This is a chosen DAG path with retained alternatives, not automatic backtracking or a globally optimal search.

The mathematical loop can explore many candidate configurations without neural calls. A real local readout remains much slower. The two-stage proof records actual calls separately from evaluations, attempts, completed passes and test injections. Do not turn numeric throughput into neural throughput or infer token savings from cache operation.

## Motion and browser adapters

A retargetable spring preserves position and velocity at target changes. Its ledger records signed target work separately from damping loss. Bounded timeline projection and interpolation are presentation choices; they do not preserve the original spring energy. GSAP consumes those curves and coordinates page/interaction effects. Lenis supplies scroll position on the host clock with explicit seconds-to-milliseconds conversion.

Tilt is an opt-in calibrated input. The adapter handles orientation, bounded targets, elapsed-time damping, hidden/reduced-motion suspension and disposal. Sensor APIs can exist without sensor events. Offscreen worker rendering, bounded DPR/workload, latest-input coalescing and pause behavior address browser cost. Tests on Playwright WebKit are evidence about that port, not certification of physical Safari sensors, thermal behavior or power use.

## Materials, imagery and pairing

Use linear reflectance parameters and explicit texture color spaces/channels. The analytic probe uses a named Lambert/GGX approximation with declared omissions. Physically plausible modeling and aesthetically preferred pairing are different questions. Homogeneous conductors/dielectrics and mixtures must remain distinguishable. Base color does not certify displayed luminance or overlaid-text contrast.

Pair relationships expose OKLab swatch distance, roughness/alpha/metalness differences, tile-relative versus physical texture frequencies, amplitude and lighting declarations separately. Authored bands can favor continuity or counterpoint. Multiple candidates remain available; unknowns remain unknown. Actual composite contrast and paired-material preference require separate renderer and observer evidence.

Raster analysis accepts local decoded bytes with rights/hash provenance. Source-region pixel bounds do not certify filtered, scaled, animated composites. Crop proposals use authored subjects/focal/negative-space annotations; no inferred salience or object detector is hidden in the tool.

## Typography evidence

`typography inspect` resolves state-level responsive values and text enlargement before isolating a real text specimen. `typography axes` preserves every variable axis as editable and samples bounded independent endpoints. Fontkit base metrics/outlines, DOM Range fragments, guarded baselines and Canvas drawing metrics remain separate. A marker must preserve original grapheme geometry and establish line ownership; ambiguity is null. Explicit fontkit optical-size policy does not claim resolved browser coordinates or native support. Actual wrap discontinuities remain discrete search events. Empty glyph outlines are nullable without losing pen advances, with a dated semantic migration.

## Human inspection and prose

Whole-layout technical drawings use the same portable expression evaluator as the factor engine. Proposed rectangles recompute; renderer-reported rectangles remain bound to their original receipt. The MCP App shares exact variable changes and node identity, then requests server recomputation. Inspection remains distinct from a component catalog or composer.

Diátaxis and Attention Control inform reader-purpose and organization practices. The prose command calculates section facts and authored route costs; entropy requires an explicit demand distribution. These are navigational models, not a literary beauty or cognitive-load equation. No diagnostic assumption, fixed prose style or universal vocabulary ban follows.

## Consequences and open claims

New modules are useful even if musical preference, material-pairing priors or small-model taste fail evaluation. Keep those claims falsifiable. Compare authored alternatives under controlled geometry/light/display and held-out briefs; retain project-level splits and distinguish synthetic critique from human preference. Do not report award-level design, universal material harmony, lower token cost or hitch-free native/Safari animation from a deterministic score.
