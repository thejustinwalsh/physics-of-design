# Recorded direction and observed consequences

Status: accepted, 2026-10-25.

The first gallery confused three useful but different things: authored styles, saved controls and generated decision recipes. It also demonstrated 3D while leaving ordinary content surfaces unlit. The follow-up must exercise the toolkit without attributing authored React composition to a solver.

Keep a product-scoped `DESIGN.md`. Inspect its bytes through `context inspect` and bind that identity separately from font/text/image measurement identities. A new direction invalidates decisions while unchanged measurements remain reusable. Structural section checks do not infer executable rules or approve art direction.

Use the existing energy engine and staged workflow for a concrete finite design field. Premeasure the complete independent text matrix; search combinations using those measured cells; condition expression on chosen reading variables; optionally choose each viable frontier with the one local selector; render exact finalists. Keep measured constraints, authored preference bands, discrete option work and actual selector calls separate. No second optimizer, image-luminance-to-roughness conversion or categorical motion derivative is introduced.

Finalist identity binds validator version, normalized brief, measurement identity, sources, tokens, scenarios and actual runtime. The full brief makes invalidation conservative. Hashes are integrity bindings, not signatures proving a caller ran a renderer. Numeric search results remain pending until separately validated.

DOM materials use bounded normal/light descriptors and layered CSS presentation. Their lobe, texture and shadow coefficients are authored appearance choices; the existing microfacet stack handles 3D. Test final composited text backgrounds through motion poses. The unsafe translucent control must fail even when its nominal base contrast is high.

Keep direct-manipulation controls outside geometry changed by their own input. Retain natural measurements rather than resetting them during drag; coalesce latest inputs; leave per-frame layout and React work outside the shared clock. Separate optional GPU initialization from ordinary controls. Record no-capture trajectories separately from video/trace/screenshot runs, since intrusive measurement can distort frame timing.

Technical drawings overlay actual current geometry and disclose proposal/observation differences, scale, source and scenario. Edits invalidate prior validation. Saved display controls remain explicitly distinct from executing solver replay.

Evaluate the workflow through fresh matched tasks with equal direction, assets, coding model/settings, time and feedback. Pinned Impeccable text guidance is a valid named control only within its stated guidance-only scope. Preserve failed launches, raw usage and hard behavior failures. Synthetic critique can tune rules, but cannot substitute for human preference or establish award-level quality.
