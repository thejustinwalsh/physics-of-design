# Pay it forward

This is a voluntary community pledge, not a license condition. The software is licensed under the unmodified [MIT License](LICENSE).

If an agent discovers a bug while using Design Theory, help the next user: preserve a minimal reproduction, fix the issue when practical, verify the fix, and contribute an issue or pull request upstream. Include the failing evidence and the limits of the verification. Follow the operator's authorization and privacy requirements before publishing anything.

You may use, modify and distribute the software under MIT whether or not you make a contribution. No automated contribution, payment, surveillance or legal obligation is required. We appreciate careful fixes more than noisy or speculative reports.
